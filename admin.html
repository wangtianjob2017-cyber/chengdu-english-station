A/B 卷题型管理说明

A/B 卷题型由 data/site-config.json 中的 topicGroups 管理。题型名称会影响 resources.json 中 type 字段的筛选匹配，不建议频繁改题型名称。

如果修改题型名称，请同步修改资料中的 type 字段。

词汇中心分类管理说明

词汇中心资料不放进 topicGroups。

词汇资料建议使用：category: "词汇中心"、skill: "词汇"、vocabCategory: "同步词汇" / "中考高频词" / "易错易混词" / "词汇训练"。
