后台使用说明

后台保存后会提交到 GitHub，Cloudflare Pages 通常会在 1-3 分钟内自动更新正式网站。

上传 PDF 资料

  1. 进入 ① 免费资料 / PDF 管理。
  2. 打开 资料库（资料卡片与 PDF）。
  3. 新增或编辑资料。
  4. 在 上传 PDF 文件 字段选择文件。
  5. 把 发布状态 设置为 published。

文件名建议使用英文或拼音，例如 grade9-reading-main-idea.pdf。

唯一 ID 怎么填写

唯一 ID 是系统识别资料或文章用的编号，不直接显示给普通用户。

  • 只能用英文小写、数字和短横线。
  • 不要用中文、空格、斜杠、问号或特殊符号。
  • 同一种内容里不能重复。

资料 ID 建议以 res- 开头：

res-grade9-reading-main-idea
res-vocab-100-days-plan
res-writing-upgrade-sentences

文章 ID 建议以 article- 开头：

article-reading-main-idea
article-vocab-forget
article-grade8-drop

如果文章 ID 是 article-reading-main-idea，文章详情链接通常填写：

article-detail.html?id=article-reading-main-idea

让资料出现在指定板块

  • 首页热门：打开 是否首页热门推荐。
  • 年级页：填写 适用年级。
  • A/B 卷题型页：填写 A/B 卷题型 和 资料分类 / 所属板块。
  • 词汇中心：选择 资料分类 / 所属板块: 词汇中心，并填写 词汇中心分类。

写长文章

进入 ④ Markdown 文章发布，可以用一个大编辑器写完整文章。

文章发布后，GitHub Action 会自动生成文章索引，Cloudflare Pages 随后重新部署。通常等待 1-3 分钟，再刷新 备考文章 页面即可看到新文章。

隐藏内容

不建议直接删除资料或文章。优先把 发布状态 改成 draft，这样前台不显示，后台仍可恢复。

媒体库是什么

媒体库用于管理上传文件。当前主要存放 PDF 资料，路径是 assets/downloads/。
